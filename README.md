# 碰碰改装车（Car Brawl）· 等距 2D 原型

开着亲手改装的小车冲进竞技场，撞烂对手，活到最后。

**在线试玩**：https://drlabs-code.github.io/car-brawl/ （手机竖屏或电脑浏览器）

## 操作
- 手机：左下摇杆控制方向，右下"冲刺"
- 电脑：WASD / 方向键，空格冲刺
- 用车头撞对手侧面打出 1.5x 暴击；护好自己的侧面

## 内容
- 三辆首发车：铁壁暴君 / 霓虹毒牙 / 泥岩狂兽，对战 7 辆 AI
- 撞击角度伤害、缩圈电网、经验与碎片（存于浏览器 localStorage）
- 纯 Canvas 2D，无依赖、无服务器

## 目录
- `index.html` `style.css` `game.js` `sprites/`：游戏本体
- `docs/design/`：游戏概念文档与车辆美术风格指南
- `docs/shots/`：手机尺寸截图

原型阶段，数值均为初始建议，待调参。
