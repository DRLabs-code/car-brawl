**手感通用做法**（[Solana Garden 镜头指南](https://solana.garden/guides/game-camera-systems-explained/)、[gamedev camera skill](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/main/skills/disciplines/camera-systems/SKILL.md)、[Ebitengine camera & juice](https://skills.danicat.dev/game-dev/ebitengineer/references/camera_and_juice.md)、[Elliot Couvignou《速度感》](https://elliotdev.gg/adding-the-feeling-of-speed/)、[GameDesign.gg Game Feel](https://gamedesign.gg/articles/game-feel/)）：
- 镜头跟随要和帧率无关（`1-exp(-k·dt)`），不要写成每帧固定 lerp 0.1；要加**沿速度方向的前瞻**并设上限，进出都做平滑。
- 速度感靠视野变化：3D 加大 FOV（例如 75°→85°），2D 就把镜头拉远，过渡 150–250 ms，幅度要克制。
- 震屏用 trauma²（小撞轻、大撞重）并平滑衰减；hit-stop 30–90 ms（约 2–4 帧），冻结期间镜头和 UI 照常动。
- 用速度改变操控（高速更难转）要克制，别让"开快"变成惩罚。

**本项目可借鉴的结论**
1. 手机端"绝对方向摇杆"（Bumpers.io 一类）上手最快，但需要**原地/小半径掉头**能力，不能把"摇杆往后推"自动解释为倒车。相对转向（Crash of Cars、手柄赛车）高手上限高，但新手容易打转。→ 两种都做，可以切换。
2. 冲刺要做成"有资源、有蓄力、有回报"的动作：RL 是能持续按住的能量槽，MK 是越难越强的分级奖励，RL 还有"超音速撞爆"这种撞击奖励。
3. 冲刺反馈要叠加多个通道：镜头拉远/推进、速度线、尾焰、分层音效、震动、撞击加成飘字。

## 二、现状诊断（读代码得出的具体病因）

车型参数（`CARS`）：暴君 spd 13 / acc 12 / turn 2.4；毒牙 20 / 24 / 3.2；狂兽 16 / 18 / 3.6（游戏内单位，车长约 2.6–3）。

### A. 手机摇杆（绝对方向）——"奇怪"的主要来源
| # | 病因 | 代码 | 后果 |
|---|---|---|---|
| A1 | **转弯时自动收油门**：`thr = mag·max(0, cos(|d|)·1.1 − 0.05)`，并且只在 `fwd < top·thr` 时才加速 | drive L346 | 夹角 60° 时 thr≈0.5，极速被压到一半；90° 时 thr≈0.03，**车几乎不动**。一转向就像踩了刹车，"一顿一顿"。 |
| A2 | **低速几乎转不动**：`yaw = steer·turn·clamp(fwd/6)` | L354 | 速度低于 6 时转向线性变弱。和 A1 叠加：静止时把摇杆推向侧面 → 不加速也不转 → **原地僵住**（只能靠原地慢转 0.7·turn/3，这条只对键盘生效）。 |
| A3 | **摇杆往后推 = 倒车**：夹角 >125°（倒车中 >95°）就进入倒车 | L341 | 玩家想"掉头往回开"，车却倒着走；开到 125° 附近会在倒车和前进之间来回切。绝对方向摇杆的直觉是"让车开往那边"，不是"让车尾朝那边"。 |
| A4 | **转向是"比例 + 限速"控制，会过冲**：`st = d·1.8` 在 32° 就打满，舵角每秒最多变 5（0.2 s 打满），偏航最高 = turn（狂兽 3.6 rad/s ≈ 206°/s） | L343 | 舵角有延迟、偏航很快，接近目标方向时来不及回正，会**左右摆动**（蛇行），开直线也微抖。 |
| A5 | 抓地力突变：侧滑速度 >5.5 时抓地直接减半 | L355 | 过了阈值突然变滑，手感不连续，"突然漂出去"。 |

### B. 键盘（v7 相对转向）
- 前进/倒车/转向逻辑没问题，但同样受 A2（低速转不动，只有补丁式原地转）和 A4（舵角 0.2 s 打满，没有按速度降低转向角）影响。
- 没有手刹/漂移键，高手玩不出操作。

### C. 加速 / 速度曲线
- 加速是**线性**的：每秒加 acc，直到极速，0→极速约 0.83–1.08 s。没有"起步猛、接近极速变缓"的曲线，起步缺少推背感。
- 松油门衰减 `exp(−1.6·dt)`，约 0.6 s 掉到 37%，比 RL 的滑行慢很多（RL 滑行减速只有刹车的 15%）。车"粘"在地上，惯性弱，撞击前很难攒出速度。
- `introT`、碰撞等部分没问题。

### D. 冲刺——"存在感弱"
| # | 病因 | 数值 |
|---|---|---|
| D1 | 持续太短、增量太小 | `dash=0.4 s`，每秒加 `acc·3`，极速 ×1.8。狂兽从 16 只能冲到约 28，之后按 `(fwd−top)·2.5` 回落（约 0.4 s）。**净多跑约 2–3 个车身**，看起来就像轻轻一窜。 |
| D2 | 冲刺时反而更"飘" | 冲刺中抓地 ×0.55、转向 ×0.7。冲刺像打滑，不像撞击攻击；方向不对时还会滑偏。 |
| D3 | 冷却长、而且看不清 | 冷却 3 s × dashCd，没有充能条或大号环形 CD 提示（需要确认按钮上是否有转圈），玩家不知道什么时候能用。 |
| D4 | 反馈通道太少 | 只有：4 团烟、50% 概率的尾焰粒子、`sfx('dash')`、刹车痕。**没有**镜头拉远/推进、速度线、震屏、震动、冲刺音效分层、启动顿帧、车身拉伸。 |
| D5 | 撞击回报弱 | 冲刺伤害 ×1.35，但没有专门的"冲刺撞击"飘字或特效，玩家感受不到"冲刺撞人更痛"。 |

### E. 镜头
| # | 病因 | 代码 |
|---|---|---|
| E1 | **镜头跟随和帧率相关**：每帧 `camX += (tx−camX)·0.15` | L437。60 fps 下时间常数约 0.1 s；手机掉到 30 fps 时更拖，120 Hz 屏幕更硬。不同设备手感不一致。 |
| E2 | **镜头不完全对准玩家**：目标是 `player·0.85` | 离场地中心越远，玩家越偏离屏幕中心（在 x=40 处偏 6 个单位），并且一直在漂。 |
| E3 | 没有前瞻 | 往前开时前方视野不变，看不到要撞的人，只能看到车后面。 |
| E4 | 缩放固定 `Z = H/520`（390 高时约 0.75），速度变化不影响缩放 | 没有速度感。 |
| E5 | 震屏每帧随机、每帧减 1.2（也和帧率相关），没有 trauma 曲线 | L438、L679 |
- hit-stop 0.06 / 0.09 s 合理（在 30–90 ms 区间内），保留。

## 三、改进方案（按优先级）

### P0（必须改，解决"奇怪、不流畅"）
1. **手机：绝对方向摇杆改为"转向追踪 + 不收油门"**
   - 油门 = 摇杆推的深度 `mag`，不再乘 cos(夹角)；只在夹角 >100° 时把油门降到 `mag·0.35`，让车先掉头。
   - **去掉"摇杆往后推 = 自动倒车"**。倒车只用倒车键（或摇杆拉到底并按住 0.4 s，可选）。往后推就是正常的小半径掉头。
   - 转向用 PD 控制：`st = clamp(d·2.2 − yawRate·0.25, −1, 1)`，舵角变化速度提到 10/s，消除蛇行。
   - 低速转向：`yaw = steer·turn·(0.35 + 0.65·clamp(|fwd|/5))·sign(fwd 或 1)`，静止也能以 35% 转向率原地掉头（碰碰车风格）。
2. **镜头**：帧率无关跟随 `k = 1 − exp(−10·dt)`；目标改为玩家本身（去掉 ×0.85）+ 前瞻 `vel·0.35`（上限 6 单位，平滑系数 4）；死区 0.5 单位。
3. **抓地连续化**：去掉 5.5 的硬阈值，改成 `G = G0·(1 − 0.45·smoothstep(3, 8, lat))`。

### P1（冲刺存在感）
4. **冲刺数值**：持续 0.4 → **0.55 s**；启动瞬间给冲量 `fwd = max(fwd, top·0.6) + top·0.9`（狂兽约 +14），冲刺极速 ×1.8 → **×2.0**；冲刺中抓地 ×0.55 → **×1.1**、转向 ×0.7 → **×0.85**（冲得稳、能微调）；结束后用 0.35 s 平滑回到极速。冷却 3 s → **2.5 s**，或者改成 2 格充能（每格 3 s），可以连冲两次。
5. **冲刺反馈清单**
   - 镜头：冲刺开始 80 ms 先**推近 4%**，然后 200 ms **拉远到 +10%**，结束 300 ms 回到原样；冲刺方向前瞻 ×1.6。
   - 屏幕：径向**速度线**（12–20 条，透明度 0.25），边缘轻微暗角。
   - 车：尾焰每帧都出（不是 50%）、两条轮胎尾迹、车身沿车头方向拉伸 1.08 / 压扁 0.94，持续 120 ms。
   - 启动：hit-stop 30 ms + `shake 4` + 震动 25 ms；音效分"点火→呼啸"两层，音高随速度升高。
   - 按钮：环形冷却进度 + 就绪时闪一下 + 就绪提示音。
6. **冲刺撞击回报**：冲刺中撞到人，伤害 ×1.35 → **×1.5**，推力 ×1.4，单独飘字「冲撞！」，hit-stop 0.09 s，`shake 12`，强震动。这是 RL"超音速撞爆"思路的轻量版。

### P2（进阶、长线）
7. **加速曲线**：`dv = acc·(1 − (fwd/top)^1.6)·1.35`，起步更猛、接近极速时变缓（0→80% 极速约 0.5 s）。
8. **滑行惯性**：无输入时的衰减 1.6 → **0.9**，主动刹车保持现状，撞击前更容易攒速度。
9. **高速转向衰减**：`turnRate·(1 − 0.25·clamp((|fwd|−0.6·top)/(0.4·top)))`，高速时稍难转（最多 −25%），不要过度惩罚。
10. **漂移（可选）**：键盘 Shift / 手机长按冲刺键 = 手刹漂移，按 MK 思路蓄力，松开得到 0.3 / 0.6 s 小冲刺，配蓝 / 橙火花。
11. **震屏 trauma 化**：`trauma` 取 0–1，`shake = trauma²·16`，每秒衰减 1.8；所有计时都用 dt。

### 键盘方案（在 v7 相对转向基础上）
- W/↑ 油门、S/↓ 刹车→倒车、A/D 转向（保持现状）；舵角变化速度按车速：低速 8/s、高速 5/s。
- 静止原地转向率从 0.7·turn/3 提到 0.35·turn（和手机的低速转向统一）。
- 空格冲刺；Shift 手刹/漂移（P2）。
- 可选：设置里加「键盘：车身相对 / 屏幕方向」切换（屏幕方向就是把 WASD 当作绝对方向的虚拟摇杆）。

### 手机方案
- **默认：绝对方向摇杆（改良版，P0-1）**。浮动摇杆：在左半屏任意位置按下，就以该点为中心；死区 0.12。
- **备选「经典」**：左右两个转向键，自动前进，加刹车/倒车键（Crash of Cars 风格），给喜欢相对操控的玩家。
- 冲刺键放大到 88 px，带冷却环；倒车键保留。

## 四、可切换的手感对比（提议）
- 设置 →「操控手感」三档（存 localStorage，对局中也能在暂停菜单切换）：
  - **A 当前版（v7）**：保留现在的参数，作为对照组。
  - **B 街机（推荐默认）**：P0 + P1 全部。
  - **C 漂移**：B + 低抓地 0.8 + 手刹漂移蓄力（P2-10）。
- 所有参数集中到一个对象 `FEEL[preset]`（转向增益、舵角速度、低速转向下限、油门策略、抓地、冲刺时长/冲量/倍率/冷却、镜头前瞻/缩放），方便调参。
- 调试：URL 加 `?feel=B&dbg=1` 显示速度、偏航、舵角、冷却实时曲线。
- 自动化对比测试：同一条"S 弯 + 掉头 + 冲刺撞靶"脚本，记录完成时间、偏离路线面积（蛇行程度）、"摇杆推出 → 车头转到位"的时间、冲刺净位移。目标：B 档掉头时间比 A 档短 40% 以上，冲刺净位移 ≥2 倍。
- 用已有的 `AB` 开关随机分组，`track('feel', {preset, kills, survive})` 埋点，配合真机问卷"流畅度 1–5 分"对比 A 和 B。
